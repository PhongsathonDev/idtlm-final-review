# เว็บอ่านสอบปลายภาค · 69-1IDTLM TCT1

สรุปเนื้อหา 11 กลุ่มข้อสอบ (140 ข้อ) พร้อมแบบทดสอบท้ายกลุ่มและตัวติดตามความคืบหน้า
เป็นเว็บ static ล้วน — ไม่มี build step ไม่ต้องติดตั้งอะไร

## เปิดใช้งาน

ดับเบิลคลิก `index.html` ได้เลย (เปิดด้วย Chrome / Edge / Firefox)

ถ้าต้องการเปิดผ่านเซิร์ฟเวอร์ในเครื่อง (แนะนำถ้าใช้ Safari หรือมีปัญหาเรื่องไฟล์):

```bash
cd site
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

## วิธีใช้

- **หน้าสารบัญ** — แผ่นฝน 140 วงทางขวาคือความคืบหน้า วงจะถูกฝนเมื่ออ่านผ่านแต่ละหัวข้อของกลุ่มนั้น
- **หน้ากลุ่ม** — อ่านสรุป → ดู “จุดที่มักออกสอบ” → ทบทวน “ศัพท์ที่ต้องแม่น” → ทำแบบทดสอบ
- **ทำครบทั้งกลุ่ม** — ปุ่มสำหรับฝนทั้งกลุ่มด้วยตัวเอง (กดซ้ำเพื่อล้างเครื่องหมาย)
- **โหมดโค้งสุดท้าย** — รวมจุดออกสอบทั้ง 11 กลุ่มไว้หน้าเดียว สำหรับอ่านคืนก่อนสอบ
- **สุ่มทดสอบ 25 ข้อ** — สุ่มข้อจากทุกกลุ่ม ใช้เช็กว่ายังอ่อนตรงไหน

ความคืบหน้าและคะแนนแบบทดสอบเก็บใน `localStorage` ของเบราว์เซอร์ (คีย์ `idtlm.exam.v1`)
เปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์จะเริ่มนับใหม่ — ล้างข้อมูลโดยกด Clear site data หรือลบ key นี้

## โครงสร้าง

```
site/
├── index.html          โครงหน้าเว็บ + รายการไฟล์ข้อมูล
├── assets/
│   ├── app.css         ระบบดีไซน์ทั้งหมด
│   └── app.js          router, ความคืบหน้า, แบบทดสอบ
└── data/
    └── g01.js–g11.js   เนื้อหาแต่ละกลุ่ม (4 หัวข้อ, จุดออกสอบ, ศัพท์, 5 ข้อสอบ)
```

แก้เนื้อหาได้ที่ไฟล์ใน `data/` โดยตรง — โครงสร้างของแต่ละกลุ่ม:

```js
{
  n, title, short, range, items, lead,
  sections: [{ h, p: [], li: [] }],
  focus:  [ "จุดที่มักออกสอบ" ],
  terms:  [{ t, d }],
  quiz:   [{ q, c: [4 ตัวเลือก], a: index คำตอบ, x: คำอธิบาย }],
  sources:[{ label, href, pg }]
}
```

## การจัดวางตามขนาดจอ

- **มือถือ (< 620px)** — คอลัมน์เดียว การ์ดแผ่นฝนวางใต้ข้อมูลสอบ สารบัญแสดงข้อ/จำนวนข้อ/ความคืบหน้าเป็นบรรทัดรอง
- **แท็บเล็ต (620–1179px)** — คอลัมน์อ่านกว้างขึ้น แผ่นฝนยังอยู่ใต้เนื้อหา
- **จอกว้าง (≥ 1180px)** — มีรางซ้าย (สารบัญกลุ่ม) + คอลัมน์อ่าน + **คอลัมน์ขอบกระดาษ** ด้านขวา
  ซึ่งเป็นดัชนีหัวข้อในกลุ่ม (กดเพื่อกระโดด), ความคืบหน้า, และปุ่มทำแบบทดสอบ (ตรึงตามการเลื่อน)
- **จอใหญ่ (≥ 1280px)** — สารบัญหน้าแรกเปลี่ยนเป็นตาราง (เลขที่ · ชื่อ · ช่วงข้อ · จำนวน · สถานะ) และแผ่นฝนขยายขนาด
- **จอใหญ่พิเศษ (≥ 1360px)** — คอลัมน์อ่านคงที่ ~62 ตัวอักษร และคอลัมน์ขอบกระดาษกว้าง 280px โดยจัดกลุ่มทั้งชุดให้อยู่กลางหน้า
- หน้าโหมดโค้งสุดท้ายแบ่งเป็น 2 คอลัมน์ที่ ≥ 1180px, หน้าทดสอบแสดงคะแนนในคอลัมน์ขอบกระดาษแทนที่จะอยู่ท้ายหน้า

## Deploy

- **เว็บออนไลน์ (GitHub Pages)** — https://phongsathondev.github.io/idtlm-final-review/
  เผยแพร่จากโฟลเดอร์ `site` นี้ที่ branch `main` (root) — แก้ไฟล์แล้ว commit + push เว็บจะอัปเดตเองภายใน ~1 นาที
- **Vercel** — ลากโฟลเดอร์ `site` ไปที่ vercel.com/new หรือรัน `vercel` ในโฟลเดอร์นี้
- **GitHub Pages (repo อื่น)** — push โฟลเดอร์นี้ขึ้น repo แล้วเปิด Pages ที่ branch `main` / root

หมายเหตุ: บนเว็บออนไลน์ ลิงก์ PDF ต้นฉบับ (path `../...`) จะแสดงเป็นชื่อไฟล์ธรรมดา
เพราะไฟล์สไลด์ไม่ได้ถูกอัปโหลดขึ้น repo — เปิดเวอร์ชันในเครื่องเพื่อกดลิงก์ได้

## หมายเหตุ
